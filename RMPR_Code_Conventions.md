# Brnach naming convetions
Branch name : `[type]/[scope]/[name]`.
- __[type]__ - here you should set which type of work done in this branch:
	- `feat/` - for content branches.
	- `fix/` - branch with some fixes.
- __[scope]__ - defines scope of changes:
	- `/global/` - global changes.
	- `/tag/` - tag of scope country.
- __[name]__ - short name, should describe changes that will be made in branch
